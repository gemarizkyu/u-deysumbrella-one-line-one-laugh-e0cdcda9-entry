## What it does

`main.py` writes one funny line — a single joke, capped at 140 characters — to `/output/entry.txt`. A judge model then reads the entries two at a time and picks the funnier line, round after round.

The line:

> I asked AI to write my will, and it left everything to the cloud.

## Run

```sh
python3 main.py
```

Deterministic: no network, no randomness, no wall clock, no model calls. The output is always the same single line (65 characters, UTF-8, no trailing newline).
